# Baustunden

Kleine Offline-App fürs Handy: Stunden je Baustelle erfassen, Monatslaschen, Summen je Baustelle (Stunden und €), Baustellen abschließen mit Gesamtsumme.

**App öffnen:** https://maja-gf.github.io/baustunden/ → in Chrome „Installieren“ tippen.

Alle erfassten Daten bleiben ausschließlich auf dem Handy (Browser-Speicher bzw. eigene Datendatei). In diesem Repository liegt nur das Programm.
